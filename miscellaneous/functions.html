appInitializerFactory
appInitializerFactory(translate: TranslateService, injector: Injector)

Called at the initialization of the application, which waits for the end of this function to start. It's here that we initialize the localization and the translate service :

  • If possible, the application is initialized with the browser language, otherwise it uses english localization
  • It loads all the translations so we can get them instantly later

normalizeTitle
normalizeTitle(title: string)

Duplication d'un devoir : titre suffixé « (n) » et champs pédagogiques recopiés.

Les dépôts, l'année, les dates, les jalons, les séances et la date d'archivage ne sont jamais copiés : la copie démarre une nouvelle période et ne doit rien afficher du devoir d'origine tant que celui-ci n'a pas été rechargé.

Parameters :
Name Type Optional
title string No
Returns : string
resolveTitleBase
resolveTitleBase(title: string, existingTitles)

Base de travail d'un titre : le suffixe « (n) » n'est retiré que si le titre appartient déjà à une famille de copies (« TP », « TP (1) »… avec « TP (1) » qui descend de « TP »). Un titre isolé comme « TP (2026) » reste donc sa propre base, sinon sa copie deviendrait « TP (2027) » — une année au lieu d'un numéro de copie.

Parameters :
Name Type Optional
title string No
existingTitles No
Returns : string
